# 🎮 オセロ AI対戦

AIとのオセロゲーム。ミニマックスアルゴリズムを使用したスマートなAI対手と対戦できます。

## 🎯 機能

- **スマートAI対手** - ミニマックスアルゴリズムを使用した知的なAI
- **フルオセロ実装** - 正確なルール判定と有効な移動の自動計算
- **美しいUI** - モダンで直感的なインターフェース
- **リアルタイムスコア** - 常に現在のスコアを表示
- **3段階難易度** - easy, medium, hard から選択可能

## 🎮 遊び方

1. `index.html` をブラウザで開く
2. 黄色い点で示された場所をクリックして黒い石を置く
3. AIが自動的に白い石を置く
4. 相手の石を挟むと、その石があなたのものになる
5. 置ける場所がない場合は「パス」ボタンをクリック

## 📁 ファイル構成

| ファイル | 説明 |
|---------|------|
| `index.html` | ゲームのHTMLテンプレート |
| `style.css` | レスポンシブなスタイルシート |
| `othello.js` | ゲームロジック（盤面管理、ルール判定） |
| `ai.js` | AI実装（ミニマックスアルゴリズム） |
| `main.js` | UIコントローラーとゲーム制御 |

## 🤖 AI戦略

- **コーナーとエッジを優先** - 戦略的に重要な位置を評価
- **相手の選択肢を制限** - 相手が置ける場所を最小化
- **先読み** - 数手先の結果を予測して最適な手を選択

## 🎛️ 難易度の変更

`main.js` の以下の行で難易度を変更できます：

```javascript
this.ai = new OthelloAI('medium'); // 'easy', 'medium', 'hard'
```

- **easy**: 2手先を予測（軽い）
- **medium**: 4手先を予測（バランス型）
- **hard**: 6手先を予測（強い）

## 🚀 使い方

ブラウザで直接プレイできます。ローカルサーバーの起動も不要です：

```bash
# ブラウザで開く
open index.html
```

または、簡単なHTTPサーバーで実行：

```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server
```

## 📝 ルール

- 黒が先手
- 盤の上に石を置く
- 相手の石を自分の石で挟むと、挟まれた石が自分のものになる
- 置ける場所がない場合はパス
- 両者とも置ける場所がなくなったらゲーム終了
- 盤に残った自分の石が多い方が勝ち
